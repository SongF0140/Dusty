# 关于我 / About Me

你好，我是 **Dusty**。

一个在代码世界里探索底层原理与智能本质的学习者。从晶体管的物理开关到神经网络的向量空间，我对"计算"这件事的每一层抽象都充满好奇。

## 🧠 研究方向

- **深度学习**：全连接网络、卷积神经网络，从数学推导到代码实现
- **计算机底层**：晶体管 → 逻辑门 → CPU 执行 → 操作系统，逐层拆解
- **数据结构与算法**：链表、栈、队列、树、图，用洛谷刷题巩固
- **Linux 系统编程**：进程管理、中断机制、内核交互
- **物联网与嵌入式**：围绕 ESP32-S3、ESP-IDF、外设驱动与 FreeRTOS 构建实践笔记

## 🔧 我的项目

### [AutoGen ChatParty](https://gitcode.com/2401_88020079/autoGen_chatparty.git)

一个围绕 AI Agent 与多人聊天场景展开的聊天室项目，尝试把自动化对话、角色协作和实时交互融合在一起。它不只是普通聊天室，更像是一个可以让智能体参与讨论、辅助表达和组织信息的实验场。

### [Auto Memories Doll](https://gitcode.com/2401_88020079/Auto-Memories-Doll.git)

以"自动手记人偶"为意象的 AI 应用项目，尝试把文本生成、记忆整理与拟人化表达结合起来。它承载的是我对 AI 助手形态的探索：不只是回答问题，而是帮助记录、归纳和表达人的想法。

一个面向大模型学习的小型实践项目，用更轻量的方式理解语言模型的基本结构、训练流程和推理机制。它适合用来拆解大模型背后的核心概念：从数据、网络结构到生成逻辑，一步步把抽象知识落到代码里。
