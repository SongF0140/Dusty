# 博客文章级 RAG 实施计划

**目标：** 为后续博客助手准备可调用的文章检索与全文证据接口。

**架构：** 构建期目录提供公开文章元数据，Pagefind 提供排名，既有 Markdown 接口提供全文。检索函数接收搜索与读取依赖，便于浏览器、服务端和测试复用。

**技术：** Astro 6、TypeScript、Pagefind、Node.js 原生测试。

## 约束

- 不增加依赖、向量数据库或模型供应商假设。
- 不改动已有未提交的助手与导航功能。
- 不向客户端暴露密码文章和草稿。
- 凭据不进入公开数据。
